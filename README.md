# UI-Component-Pack

UI Component Pack | Cedar & Code
Build faster with a library of high-end, copy-paste web components. This pack is designed to bring the Cedar & Code aesthetic to any existing project.

What’s Inside:

- index.html: The component showroom.
- style.css: All necessary styles (Glassmorphism, Bento-lite, Modern Forms).
- Components included: Glassmorphism Nav, Premium Buttons, Modern Input Fields, and Service Cards.

How to Use:

1. Open the Showroom: Open index.html in your browser.
2. Copy the HTML: Find the section you want and copy the code.
3. Copy the CSS: Find the matching comment block in style.css and paste it into your project.
4. Icons: This pack uses Lucide Icons.

Customization:
To change the brand color globally, update the --primary variable in style.css.
